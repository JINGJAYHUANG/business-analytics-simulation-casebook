# Provenance and public boundary

## Independent reconstruction

The repository was created from a public-safe list of analytical competencies previously practiced in a virtual business simulation:

- supply-chain cluster analysis;
- SQL and programming practice;
- accounting-data transformation and integration;
- A/B testing;
- QA metric design and troubleshooting;
- quarterly reporting.

Everything beyond that competency list was designed independently for this repository.

## Not included

- proprietary prompts or task instructions;
- original simulation datasets;
- answer keys or grading rubrics;
- screenshots or copied reports;
- names or records of real employees, candidates, customers, or suppliers;
- claims that simulation participation was employment.

## Synthetic identity

All public fixtures are marked synthetic. The fictional company name, source systems, customers, suppliers, SKUs, transactions, experiments, and incidents do not represent real entities.
