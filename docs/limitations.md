# Limitations

- K-means assumes Euclidean geometry after standardization and can miss non-spherical structure.
- Segment names depend on synthetic target profiles and are not universal classifications.
- The accounting model is educational, not GAAP or IFRS reporting software.
- The DSO value is a simplified quarter-end proxy, not a full aging analysis.
- The experiment uses aggregated cells and normal approximations; it is not a substitute for a complete experimentation platform.
- Post-stratification addresses composition, not all threats to causal validity.
- The QA case models duplicate and retry behavior but does not reproduce a production observability stack.
- SHA-256 and event chains detect post-generation modification; they do not prove that an original source was truthful.
- Synthetic fixtures validate code paths, not real-company recommendations.
