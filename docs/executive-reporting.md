# Executive reporting

The executive report uses a decision register rather than a list of charts.

Each recommendation includes:

```text
area
decision
evidence
caveat
next action
```

## Reporting rules

- State the decision before the method.
- Name the unit and denominator near every headline number.
- Keep data-quality blockers adjacent to the affected conclusion.
- Separate observed evidence from interpretation.
- Do not convert clusters into causal language.
- Do not hide negative or conflicting results.
- State what would change the recommendation.

The report is self-contained HTML with no network dependencies, so it can be reviewed offline and hashed as part of the run bundle.
