# Case brief 1 — Supplier-lane segmentation

## Context

A fictional distributor manages many supplier-lane relationships with different cost, lead-time, service, quality, volatility, and expedite characteristics. Leadership wants differentiated operating policies rather than one universal service rule.

## Decision

Which relationships should use collaborative planning, automated replenishment, flexible capacity, or corrective-action controls?

## Deliverables

1. Validate the lane grain and feature definitions.
2. Standardize numeric features.
3. Compare candidate cluster counts.
4. Profile each selected cluster using original business units.
5. Translate profiles into operating hypotheses.
6. State why the analysis is descriptive rather than causal.

## Acceptance criteria

- no raw-unit feature dominates because of scale;
- cluster count has a documented rule;
- every lane receives one segment;
- policy recommendations include risks and a validation plan;
- no claim that clustering itself improves performance.
